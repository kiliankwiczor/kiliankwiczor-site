## Découvrir MOVA sur Windows

MOVA est une application de musculation et de communauté en cours de développement, en français. Le site personnel reste à la racine ; le projet MOVA se trouve dans [`mova/`](mova/README.md).

**[Télécharger MOVA prêt à ouvrir pour Windows 64 bits — environ 47 Mo](https://github.com/kiliankwiczor/kiliankwiczor-site/raw/refs/heads/main/mova/downloads/MOVA-Pret-a-ouvrir-Windows.zip)**

1. Téléchargez l’archive, puis faites **clic droit → Extraire tout**.
2. Ouvrez le dossier `MOVA` extrait et double-cliquez sur **OUVRIR-MOVA.cmd**.
3. Gardez la fenêtre ouverte : le navigateur affiche l’application à `http://127.0.0.1:8080`.

Aucun Node.js ni Docker à installer. Créez un compte de test dans l’application. Les données et la communauté de cette version restent sur votre ordinateur. Un push GitHub conserve les fichiers ; il ne déploie pas le backend sur Internet.

**Pilote local, pas encore une version commerciale.** Les achats et vrais emails sont désactivés et les contenus sportifs restent à valider. Le moteur commun et les parcours ont été testés sous Linux ; le double-clic Windows reste à confirmer sur un ordinateur Windows. Consultez le [guide Windows](mova/WINDOWS.md), les [fonctionnalités et limites](mova/FEATURE_STATUS.md) et les [instructions de développement](mova/README.md).

L’archive inclut le moteur Node.js officiel et les licences des composants. Son empreinte est disponible dans [`mova/downloads/MOVA-Pret-a-ouvrir-Windows.zip.sha256`](mova/downloads/MOVA-Pret-a-ouvrir-Windows.zip.sha256).
